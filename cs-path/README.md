# CS Path

Публичный учебный маршрут: https://3mil1.github.io/cs-path/

Статическая страница без зависимостей. `index.html` содержит CSS, приложение и встроенный каталог. Прогресс хранится только в localStorage браузера; JSON экспорт/импорт переносит отметки между устройствами.

Каталог редактируется в `courses.json`. После изменения выполнить `python3 build.py`, чтобы обновить встроенные данные в `index.html`. Затем коммитить оба файла. Публикация — существующий GitHub Pages из `master:/`.

Основной маршрут — 12 курсов, резерв — 5. Материалы и соответствия проверены 17 ноября 2026 года. Учебные среды и автопроверки университетов не запускались. Подробности — `learning-plan.md` и `mit-course-evidence.md`.
