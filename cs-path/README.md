# CS Path

Публичный учебный маршрут: https://3mil1.github.io/cs-path/

Статическая страница без зависимостей. `index.html` содержит CSS, приложение и встроенный каталог. Прогресс хранится только в localStorage браузера; JSON экспорт/импорт переносит отметки между устройствами.

Каталог и переводы описаний редактируются в `courses.json`; тексты интерфейса — в `ui-translations.json`. После изменения выполнить `python3 build.py`: он проверит полноту переводов, обновит встроенные данные в `index.html` и создаст планы `learning-plan.en.md` / `learning-plan.et.md`. Коммитить исходные JSON и сгенерированные файлы вместе. Публикация — существующий GitHub Pages из `master:/`.

Основной маршрут — 12 курсов, резерв — 5. Материалы и соответствия проверены 17 ноября 2026 года. Учебные среды и автопроверки университетов не запускались. Подробности — `learning-plan.md` и `mit-course-evidence.md`.

Языки интерфейса: English (`en`, по умолчанию), Eesti (`et`), Русский (`ru`). Выбор сохраняется отдельно от прогресса, в `cs-path-language-v1`. Явная ссылка `?lang=en|et|ru` имеет приоритет над сохранённым выбором. Исходные материалы университетов остаются на английском; архив проверки MIT помечен как русский.
