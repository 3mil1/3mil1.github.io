# UT × MIT × CMU — study plan

Independent study path · materials checked on November 17, 2026.

Original course materials are in English.

Matches are by topic, without credit recognition. Assignment code, learning environments and autograders have not been run.

## Getting started

After roughly half a year at UT, start by strengthening your mathematical foundations. Work on one supplementary course at a time.

PS1, Problem 1 · 30–45 minutes

Prove the irrationality of `log₄6`.

[PS1](https://openlearninglibrary.mit.edu/assets/courseware/v1/432a6320bb11c2bfba8ed2a47e68f86d/asset-v1:OCW+6.042J+2T2019+type@asset+block/MIT6_042JS15_ps1.pdf)

## How to study

Start with 3–5 extra hours per week alongside UT. This is a suggested schedule for selected topics. Full MIT and CMU courses usually require considerably more time.

Start with a question from your current subject. Find the relevant lecture or reading, work through an example, close the material and explain the idea in your own words.

CMU 17-214 and MIT 6.031 overlap. Introductory courses 15-110 and 6.0001 are useful if you have gaps in the basics. Optional courses are alternatives, not extra requirements.

## Courses by module

### MIT 6.042J — Mathematics for Computer Science

Spring 2015 · M1 / M2 / M7

Start here · Videos + problems

Logic, proofs, induction, sets, graphs and counting. A mathematics companion for the first UT modules and a foundation for algorithms.

**How to use it:** Choose the section that matches your current UT topic. If basic logic is already comfortable, move on to proofs and induction.

**Before you start:** MIT lists single-variable calculus as a prerequisite for the full course. The introductory logic sections can be studied separately.

Homework problem-set solutions are not public. The feedback buttons in OLL have not been tested.

### CMU 17-214 — Principles of Software Construction

Spring 2023 · M2 / M4 / M8

Next step · Slides + examples

Specifications, testing, object-oriented design, responsibility assignment, refactoring and APIs. Connect each topic to your UT project.

**How to use it:** Start with OO basics, Specifications and Unit Testing, and Test Case Design. Take the full course once you are confident in programming.

**Before you start:** Roughly two semesters of programming, basic data structures and invariants. Examples use Java and JavaScript/TypeScript.

Slides are public. External access to the complete assignment workflow is unverified. This edition differs from Agentic Software Development in 2026.

### MIT 6.041SC — Probabilistic Systems Analysis

Fall 2013 · M4 / M6

Probability → statistics · Videos + problems + solutions

Probability models, conditional probability and random variables. Later sections cover estimation and hypothesis testing for M6 statistics.

**How to use it:** Start with discrete models and conditional probability. Move to Unit IV after building a probability foundation.

### CMU 15-445 — Introduction to Database Systems

Fall 2025 · M4 / M8

Start with SQL · Videos + assignments

Relational models, SQL, indexes, transactions and database internals. In your first year, start with lectures 1–2 and the SQL homework.

The site links to homework solutions. The environment, dataset and autograder have not been run in this review.

### MIT 6.004 — Computation Structures

Spring 2017 · M5

Computer architecture · Videos + worksheets + answers

From digital logic and state machines to processor instructions, memory and caches. Connect hardware to program execution.

**How to use it:** Match chapters to Computer Architecture and Organisation in M5. Work through the worksheets after each section.

**Before you start:** Basic programming; MIT formally lists 8.02 as a prerequisite.

Uses the educational Beta architecture. Not all lab environments and simulators have been checked by running them.

### MIT 18.06SC — Linear Algebra

Fall 2011 · Gilbert Strang · M5

Mathematics for systems and ML · Videos + problems + solutions

Linear systems, vector spaces, bases, projections and eigenvalues. Gilbert Strang’s lectures are accompanied by problems and worked solutions.

**How to use it:** Solve the associated exercises after each session. Explain the geometric meaning of matrix operations.

**Before you start:** School algebra, vectors and coordinates. Calculus is not needed to start learning linear algebra.

Linear algebra does not replace abstract algebra on groups and fields.

- [Course](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/)

### CMU 15-213 — Introduction to Computer Systems

Course site + CS:APP self-study · M5 / M8

After C and pointers · Materials + self-study labs

A programmer’s view of machine code, memory, processes, I/O and concurrency. Practical work explains what happens beneath your code.

**How to use it:** Start after learning C and becoming comfortable with pointers. Begin with data representation, then machine code and memory.

**Before you start:** C, pointers and basic data structures. The official prerequisite is 15-122.

Some labs require Linux/x86-64; Cache Lab explicitly requires x86-64. Lab solutions are provided to instructors. This is not a complete course in implementing an OS kernel.

- [Course](https://www.cs.cmu.edu/~213/)
- [Self-study labs](https://csapp.cs.cmu.edu/3e/labs.html)

### MIT 6.036 — Introduction to Machine Learning

Fall 2020 · M6

After the mathematics foundation · Videos + text · OLL

Framing machine-learning problems, generalisation, linear models, neural networks and reinforcement learning.

**How to use it:** Start after Python, linear algebra and calculus. Check your understanding by solving problems, not just watching lectures.

**Before you start:** Python, calculus and linear algebra. Probability helps with model evaluation.

The checked Homework 1 and self-assessment pages require sign-in and enrolment. Assignment and autograder access after sign-in is unverified. Classical AI is not fully covered.

Spring 2011 · M6 / M8 / M11

### MIT 6.006 — Introduction to Algorithms

Fall 2011 · M7

After discrete mathematics · Videos + problems + solutions

Sorting, hashing, trees, graphs, shortest paths and dynamic programming. A substantial supplement to M7 algorithms.

**How to use it:** Analyse correctness and complexity before implementation. Start with Peak Finding, then PS1.

**Before you start:** Confident Python programming and discrete mathematics at the level of 6.042J.

This edition’s starter code uses Python 2.7. Compatibility with modern Python is unverified. The course does not replace formal languages and computability.

**How to use it:** Skip it if the basic constructs are already familiar. PS1: House Hunting is useful practice for state and loops.

Python may differ from the UT course language. Homework solutions are not published; older installation instructions are unverified.
